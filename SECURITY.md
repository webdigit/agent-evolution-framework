# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to hello@webdigit.be. Include the
affected AEF version, a concise reproduction, and the potential impact. Do not
include secrets or personal data that are not necessary to assess the report.

Please do not open a public issue for an undisclosed vulnerability. WEBDIGIT
SRL will acknowledge the report and coordinate disclosure when appropriate.

Only the latest published release is supported with security fixes.
