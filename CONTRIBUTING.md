# Contributing

Issues, bug reports, and focused suggestions are welcome. Search existing
issues first and provide a minimal reproduction when reporting a defect.

AEF does not accept code contributions without prior written agreement from
WEBDIGIT SRL. Before preparing a pull request, contact hello@webdigit.be and
wait for confirmation. Unsolicited pull requests may be closed without review.

Never include credentials, private workspace state, or third-party confidential
information in an issue or proposed contribution.

By participating, you agree to follow the repository license and applicable
GitHub community standards.
